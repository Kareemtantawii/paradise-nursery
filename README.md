# Paradise Nursery - Online Plant Shop

This is a React-based e-commerce web application for a plant shop called Paradise Nursery. Users can browse plants grouped into categories, add them to a shopping cart, adjust quantities, and view the total cost. The cart state is managed with Redux Toolkit.

## Features
- Display plants by category (e.g., Indoor, Outdoor, Succulents)
- Add to cart with button disabling and cart count update
- Cart page with quantity controls, delete items, total cost
- Responsive navigation bar with links to Home (product listing), Plants, and Cart
- Checkout button shows "Coming Soon" message

## Technologies
- React (functional components, hooks)
- Redux Toolkit (state management)
- CSS for styling
